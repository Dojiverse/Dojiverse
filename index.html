Meridian

Python · FastAPI · Pydantic · Hypothesis · Docker · Google Cloud Run · GitHub Actions · React
Tax-aware rebalancing engine for registered investment advisers · live demo

An engine that keeps a client's portfolio on target without creating tax bills it did not need to. It chooses which tax lots to sell, screens every sale against the IRS wash-sale rule across the whole household, harvests losses when they are worth taking, runs the result through the client's investment policy, and records every decision in a hash-chained audit log. Exact decimal arithmetic end to end, 400 property-based tests, and a two-year synthetic history the engine ran itself.
